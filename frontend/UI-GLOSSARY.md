# Словарь блоков интерфейса

Этот файл — единый словарь для постановок по интерфейсу. В задачах используем **название блока** из столбца «Как называем»; при необходимости разработчик может найти его по компоненту или CSS-классу.

## Общая оболочка приложения

| Как называем | Что это | Компонент / CSS |
| --- | --- | --- |
| Левая навигация | Закреплённая боковая панель со всеми разделами | `sidebar` |
| Брендовый блок | Логотип в верхней части левой навигации | `brand`, `brand-logo` |
| Переключатель рабочего пространства | Блок «Рабочее пространство — Ростелеком» | `workspace` |
| Главное меню | Список пунктов навигации, сгруппированный по разделам | `nav`, `nav-item`, `nav-label` |
| Карточка помощи | Блок «Нужна помощь?» внизу навигации | `help-card` |
| Мини-профиль | Карточка пользователя и переключатель роли внизу | `user-mini`, `role-select` |
| Рабочая область | Правая часть приложения, в которой открываются страницы | `main`, `content` |
| Заголовок страницы | Название раздела и кнопки действий справа | `PageHeader`, `page-header`, `page-actions` |
| Базовая кнопка | Стандартная контурная или фиолетовая кнопка | `Button`, `button`, `button primary` |
| Карточка / панель | Белый контейнер с рамкой и скруглением | `panel` |
| Уведомление | Всплывающее сообщение об успешном действии | `toast` |
| Карточка вуза (модальное окно) | Окно с подробностями выбранного вуза | `UniversityModal`, `modal` |

| Как называем | Что это | CSS |

| Основная кнопка входа | Кнопка «Войти» | `login-submit` |
| Разделитель демо-входа | Линия с текстом «или» | `login-divider` |
| Роли для демо-входа | Набор кнопок для входа в роли | `login-demo`, `login-demo-chips`, `login-demo-chip` |

## Примеры точных постановок

- «В **KPI-карточках** на дашборде увеличить отступ между карточками».
- «В **карточке входа** сделать логотип меньше, а **основную кнопку входа** выше».
- «В **колонке этапа „Демонстрация“** изменить фон, не меняя остальные колонки».
- «В **строке вуза** реестра перенести **метку статуса** перед названием менеджера».
- «На шаге 2 импорта изменить только **таблицу сопоставления**».
