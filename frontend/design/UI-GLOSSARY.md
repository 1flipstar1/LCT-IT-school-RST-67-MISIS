# Словарь интерфейса

Единые названия экранов и блоков для постановки задач. В задаче пишем название из колонки «Как называем» — разработчик найдёт компонент по колонке «Где в коде».

## Каркас

| Как называем | Что это | Где в коде |
| --- | --- | --- |
| Левая навигация | Меню разделов, справка и карточка пользователя | `layout/Sidebar.jsx` |
| Группы меню | Основные экраны без подписи, «Данные», «Управление» (видны по правам) | `layout/navigation.js` |
| Счётчик в меню | Оранжевое число: срочные взаимодействия или новые записи интеграций | `Sidebar.jsx → useNavigationBadges` |
| Мобильная шапка | Кнопка меню и логотип на телефоне и планшете | `layout/AppLayout.jsx` |
| Режим раскладки | Телефон / планшет / компьютер по ширине окна с учётом масштаба интерфейса; смена режима анимируется (GSAP Flip) | `lib/layoutMode.js` |
| Выезжающее меню | Левая навигация на телефоне и планшете: GSAP-анимация, закрытие свайпом влево, Esc или тапом по затемнению | `layout/useNavDrawer.js` |
| Шапка страницы | «Назад», заголовок, пояснение и главные действия | `ui/PageHeader.jsx` |
| Уведомление | Сообщение внизу экрана, часто с кнопкой «Отменить» | `ui/Toast.jsx` |
| Страница ошибки | Код ошибки, объяснение и выход | `features/errors/ErrorPage.jsx` |

## Экраны

| Экран | Адрес | Для кого | Главное на экране |
| --- | --- | --- | --- |
| Вход | — | все | Keycloak и демо-вход по ролям |
| Дашборд | `#/` | все | Распределение по этапам, показатели, события и список взаимодействий |
| Взаимодействия | `#/interactions` | все | Фильтры, вид «Таблица» / «Доска» |
| Карточка взаимодействия | `#/interactions/:id` | все | Текущий этап, история, файлы, данные договора, путь по этапам |
| Вузы | `#/universities` | все | Список вузов со срочными и ответственными |
| Карточка вуза | `#/universities/:id` | все | Показатели LMS, взаимодействия, контакты |
| Аналитика | `#/analytics` | все | Динамика заявок, рейтинг направлений, этапы, нагрузка |
| Отчёты | `#/reports` | все | Конструктор отчёта, предпросмотр, история |
| Справочники | `#/catalogs` | все (загрузка — руководитель, админ) | Вузы, направления, продукты, ответственные |
| Загрузка из Excel | `#/catalogs/import` | руководитель, админ | Мастер: файл → сопоставление → проверка → готово |
| Этапы работы | `#/workflows` | руководитель, админ | Конструктор этапов (workflow из ТЗ) |
| Интеграции | `#/integrations` | руководитель, админ | Источники LMS и сайта, Telegram-бот (настроен ли, сколько руководителей подключено), входящие записи, журнал |
| Пользователи и доступ | `#/users` | админ | Роли, видимость данных, блокировка |
| Журнал действий | `#/audit` | руководитель, админ | Кто, что и когда менял |
| Справка | `#/help` | все | Руководства, коды ошибок, о системе |
| Настройки профиля | `#/profile` | все | Аватарка; масштаб интерфейса (100–130%, по умолчанию 110%); анимации, всплывающие пояснения, счётчики меню; стартовая страница, вид и сортировка взаимодействий; время показа уведомлений, горячие клавиши; повтор курса новичка. У всех сотрудников первым идёт баннер «Уведомления в Telegram» (после подключения — строка состояния). Хранятся на сервере в карточке сотрудника. Открываются по нажатию на профиль внизу левой навигации |

## Блоки

| Как называем | Что это | Где в коде |
| --- | --- | --- |
| Панель фильтров | Поиск, период, вузы, направления, продукты, ответственные | `features/filters/FilterBar.jsx` |
| Плитка показателя | Крупное число с подписью, ведёт к списку (аналитика) | `ui/StatTile.jsx` |
| Распределение по этапам | Кольцо этапов на главной с подписями фаз | `legacy/DashboardScreen.jsx` («Распределение заявок по этапам») |
| Показатели главной | Вузы в работе, договоры за месяц, актуализированные программы | `legacy/DashboardScreen.jsx` → `Kpi` |
| Требуют внимания | Список этапов с вышедшим или близким сроком, самые срочные сверху | `legacy/DashboardScreen.jsx` («Требуют внимания») |
| Последние действия | Лента недавних изменений и таблица заявок | `legacy/DashboardScreen.jsx` («Последние действия», «Заявки») |
| Полоса фильтров главной | Менеджеры и переход к списку взаимодействий | `legacy/DashboardScreen.jsx` → `PageHeader` |
| Метка срока | «Просрочено на 2 дня», «Осталось 1 день», «В срок» | `interactions/components/SlaBadge.jsx` |
| Прогресс этапа | «6 из 14» + название + полоса | `interactions/components/StageProgress.jsx` |
| Доска этапов | Колонки этапов по фазам с перетаскиванием | `interactions/components/InteractionBoard.jsx` |
| Окно смены этапа | Выбор этапа, комментарий, файлы | `interactions/TransitionDialog.jsx` |
| Удаление заявки | Кнопка «Удалить заявку» в характеристиках заявки (руководитель, админ) и окно подтверждения; отменяется из уведомления | `interactions/DeleteInteractionDialog.jsx` |
| Лента событий | История переходов, комментариев и файлов | `interactions/components/EventFeed.jsx` |
| Путь взаимодействия | Вертикальный список этапов с отметками | `interactions/components/StageStepper.jsx` |
| Данные договора | Поля из шаблона импорта, режим редактирования | `interactions/components/ContractDetails.jsx` |
| Карточка графика | График + «Таблица» + скачивание PNG | `ui/charts/ChartCard.jsx` |
| Таблица | На телефоне превращается в карточки | `ui/DataTable.jsx` |

## Примеры точных постановок

- «В **метке срока** для просроченных показывать дату, а не количество дней».
- «На **доске этапов** сделать колонки шире на планшете».
- «В **окне смены этапа** сделать комментарий обязательным и при переходе вперёд».
- «В **панели фильтров** на странице „Отчёты“ добавить фильтр по этапам».
