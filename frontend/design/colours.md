# Фирменная палитра

| Название | HEX | Назначение |
|---|---|---|
| Фон базы | `#f4f4f5` | Основной фон приложения |
| Фон левой панели | `#ffffff` | Сайдбар и панели навигации |
| Фиолетовый | `#8300ff` | Основной брендовый акцент, кнопки и активные состояния |
| Фиолетовый tier 2 | `#f0e0ff` | Светлые выделения, бейджи и фон активных элементов |
| Оранжевый | `#ff4f12` | Предупреждения, важные действия и акценты |
| Оранжевый tier 2 | `#ffeae2` | Светлый фон предупреждений и оранжевых бейджей |
| Серый | `#f4f4f5` | Нейтральные поверхности и вторичный фон |

## В коде

Токены — в `src/styles/tokens.css`. Компоненты используют только их, без HEX-значений в стилях.

| Токен | HEX | Назначение |
|---|---|---|
| `--color-brand` | `#8300ff` | Главные кнопки, активные пункты, графики |
| `--color-brand-hover` / `--color-brand-active` | `#6f00db` / `#5c00b5` | Наведение и нажатие |
| `--color-brand-soft` / `--color-brand-softer` | `#f0e0ff` / `#f8f1ff` | Фон активных элементов и выделений |
| `--color-accent` | `#ff4f12` | Счётчики в меню, иконки предупреждений |
| `--color-warning-text` / `--color-warning-soft` | `#b3380b` / `#ffeae2` | Текст и фон «Просрочено» |
| `--color-bg` / `--color-surface` | `#f4f4f5` / `#ffffff` | Фон приложения и карточек |
| `--color-text` / `--color-text-secondary` / `--color-text-tertiary` | `#1d1d22` / `#56565f` / `#6e6e78` | Основной, вторичный и вспомогательный текст |

## Контраст (WCAG 2.1 AA)

Все пары «текст / фон» — не ниже 4.5:1: основной текст на белом 16.8, вторичный 7.3, вспомогательный 5.0, фиолетовый на белом 6.2, текст предупреждения на его фоне 5.2.
Чистый оранжевый `#ff4f12` на белом даёт 3.3:1 — поэтому им не пишем текст, только иконки и заливки.
