# Типографика

Правила типографики интерфейса соответствуют гайду Дизайн-системы Ростелекома 2-го поколения (Атомаро): https://design.rt.ru/gen2/basics/typography/preview

## Шрифт

Для интерфейса используется гарнитура **Rostelecom Basis** (локальные файлы в [`design/font/`](font)).

| Начертание | Файл | Веса (font-weight) | Назначение |
|---|---|---|---|
| Light | `RostelecomBasis-Light.otf` | 300 | крупная акциденция (по необходимости) |
| Regular | `RostelecomBasis-Regular.otf` | 400 | основной текст интерфейсов |
| Medium | `RostelecomBasis-Medium.otf` | 500, 600 | акцентный текст, кнопки, «strong»-варианты |
| Bold | `RostelecomBasis-Bold.otf` | 700, 800 | заголовки |

Подключение (`@font-face` в `src/styles.css`) и принудительное применение ко всем элементам:

```css
body *,button,input,select{font-family:'RostelecomBasis',sans-serif!important}
```

### Кнопки

Кнопки рендерятся компонентом `AtomaroButton` из `@atomaro/ui-kit`; размер шрифта управляется переменными кита. Переопределены на Medium 500 (вместо SemiBold 600):

```css
.button,.atomaro-button{font-size:14px;line-height:20px;font-weight:500}
```

## Правила использования

1. Заголовки — только Bold (700), начертание «strong» (500) — для акцентов внутри основного текста.
2. Основной текст — Regular (400); не использовать начертание Light для контента.
3. Межбуквенная разрядка применяется только к Description-стилям (0.2px / 0.4px).
4. Для микро-лейблов в верхнем регистре (eyebrow, nav-label, колонки таблиц) допустима расширенная разрядка 1.2–1.3px.
5. Минимальный кегль в интерфейсе — 10px (description-s); мельче — нельзя.
6. Не использовать системные шрифты: всё наследует Rostelecom Basis через `body * {font-family:...!important}`.
