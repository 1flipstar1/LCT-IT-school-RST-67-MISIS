# Типографика

Правила типографики интерфейса соответствуют гайду Дизайн-системы Ростелекома 2-го поколения (Атомаро): https://design.rt.ru/gen2/basics/typography/preview

## Шрифт

Для интерфейса используется гарнитура **Rostelecom Basis** (локальные файлы в [`design/font/`](font)).

| Начертание | Файл | Веса (font-weight) | Назначение |
|---|---|---|---|
| Light | `RostelecomBasis-Light.otf` | 300 | крупная акциденция (по необходимости) |
| Regular | `RostelecomBasis-Regular.otf` | 400 | основной текст интерфейсов |
| Medium | `RostelecomBasis-Medium.otf` | 500, 600 | акцентный текст, кнопки, «strong»-варианты |
| Bold | `RostelecomBasis-Bold.otf` | 700, 800 | заголовки |

Подключение (`@font-face` в `src/styles.css`) и принудительное применение ко всем элементам:

```css
body *,button,input,select{font-family:'RostelecomBasis',sans-serif!important}
```

## В коде

Токены — в `src/styles/tokens.css`, подключаются как `font: var(--font-h1)`.

| Токен | Стиль шкалы | Где используется |
|---|---|---|
| `--font-display` | display-m 42/44/700 | Крупные числа в плитках показателей |
| `--font-h1` | heading-h1 28/32/700 | Заголовок страницы |
| `--font-h2` | heading-h2 22/24/700 | Название этапа в карточке, итоги импорта |
| `--font-h3` | heading-h3 18/20/700 | Заголовки диалогов и статей справки |
| `--font-h4` | heading-h4 16/20/700 | Заголовки карточек |
| `--font-body-m`, `--font-body-m-strong` | body-m 16/24 | Пояснения под заголовками, текст справки |
| `--font-body-s`, `--font-body-s-strong` | body-s 14/20 | Основной текст интерфейса, таблицы, поля |
| `--font-caption`, `--font-caption-strong` | description-l 12/16 | Подписи, метки, даты |

Минимальный размер текста в интерфейсе — 12 px (description-l): мелкие 10–11 px плохо читаются на рабочих мониторах.
Шрифты кита Атомаро переопределены на Rostelecom Basis (`--font-family-*`, `--button-*-font`).

## Правила использования

1. Заголовки — только Bold (700), начертание «strong» (500) — для акцентов внутри основного текста.
2. Основной текст — Regular (400); не использовать начертание Light для контента.
3. Межбуквенная разрядка применяется только к Description-стилям (0.2px / 0.4px).
4. Для подписей групп в верхнем регистре (фазы на графиках и доске) допустима разрядка 0.4px.
5. Минимальный кегль в интерфейсе — 12px (description-l); мельче — нельзя.
6. Не использовать системные шрифты: гарнитура задаётся токеном `--font-family`, шрифты кита Атомаро переопределены в `tokens.css`.
