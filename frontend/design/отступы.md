# Отступы

Правила отступов интерфейса соответствуют гайду Дизайн-системы Ростелекома 2-го поколения (Атомаро): https://design.rt.ru/gen2/basics/typography (раздел «Отступы»).

## Принцип

- Токены отступов **spacing** вычисляются из базового значения и образуют фиксированную шкалу.
- Токен привязан к модулю **4px** при `spacing.base = 16px`:
  - `spacing.0,5x` — половина модуля = 2px;
  - `spacing.2x` — два модуля = 8px;
  - и т.д.
- Использование случайных величин запрещено: все padding/margin задаются только токенами шкалы.

## В коде

Токены `--space-0_5x` … `--space-16x` — в `src/styles/tokens.css`, значения совпадают со шкалой выше.
Стили компонентов лежат рядом с ними (CSS Modules) и используют только эти токены.

Основные значения каркаса:

| Где | Отступ |
|---|---|
| Поля рабочей области (десктоп / планшет / телефон) | `8x` / `6x` / `4x` |
| Внутренние отступы карточки (десктоп / телефон) | `6x` / `4x` |
| Расстояние между карточками и плитками | `4x` |
| Ячейки таблицы | `3x` по вертикали, `4x`–`6x` по горизонтали |
| Поля и кнопки внутри форм | `4x`–`5x` между полями |

## Правила использования

1. Отступы задаются только токенами шкалы `--space-*` — никаких произвольных значений.
2. `spacing.4x` (16px) — базовый модуль; для плотных интерфейсов допустимо уменьшение до `2x` (8px), для просторных — увеличение до `6x`–`8x`.
3. Внутренние отступы компонентов описываются компонентными токенами, которые ссылаются на токены spacing (в проекте — напрямую `var(--space-*)`).
4. Не использовать значения вне шкалы (например 10px, 13px, 15px, 17px, 22px, 25px, 30px, 36px, 50px, 55px, 60px, 66px…).
5. Для размеров элементов, не являющихся отступами (высоты кнопок, ширины колонок, радиусы), шкала spacing не применяется.
